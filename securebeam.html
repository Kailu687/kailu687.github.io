SeCure BEAM — Laser-Based Optical Wireless Communication

SeCure BEAM is a half-duplex optical wireless communication prototype developed during my first semester as part of the Physics of Semiconductor Devices course.

The project explores how information can be transmitted through a focused laser beam using Morse code, with an Arduino-controlled laser transmitter and a light-dependent resistor (LDR) receiver. Text messages are converted into timed light pulses, transmitted through free space, and reconstructed at the receiving station using pulse-duration and timing-gap detection.

Beyond the hardware, I also worked on microcontroller firmware and a Python-based desktop interface for serial communication and system monitoring. The project was successfully demonstrated and submitted, giving me my first practical experience in integrating electronics, embedded programming, and communication principles into a working system.

How it works:


Key Features:

  • Laser-based optical communication  : Transmits information through a free-space optical path instead of a conventional wired data connection or radio link.  
  • Morse-code encoding and decoding  : Maps text to timed dots and dashes, then reconstructs characters from detected pulse durations and inter-symbol gaps.  
  • Embedded firmware  : Uses Arduino C++ for GPIO control, analog sensor acquisition, timing logic, serial commands, and transmission feedback.  
  • Desktop interface : A Python Tkinter GUI with PySerial for serial-port selection, message transmission controls, and serial-output monitoring.

ChallengeHow we overcomed it

Unreliable raw-binary decoding  

Transitioned to Morse-coded pulses with timing-based symbol recognition.  

Ambient-light interference  

Protected the sensors with black insulation tape and made a path with a PVC pipe to provide zero light interference.
Inverted and inconsistent Light Detection 

Investigated the sensor output polarity and adapted the receiver logic to the actual circuit behavior.  

Serial communication errors

Investigated COM-port access and Arduino upload configuration issues.


Outcome & Learning

Successfully demonstrated and submitted a working Morse-code-based optical communication prototype.

The project introduced me to practical semiconductor optoelectronics, analog sensor behavior, embedded firmware development, timing-sensitive communication, and iterative hardware debugging.

It also taught me an important engineering lesson: a communication system is only as reliable as its sensing, timing, synchronization, and environmental tolerance. Moving away from the initial raw-binary approach helped me appreciate the trade-offs involved in choosing a signaling method for a simple hardware platform.
