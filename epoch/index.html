EPOCH

Give it a dataset. Epoch picks the method.

Epoch is a local-first AutoML workbench for tabular data. It analyses your dataset, chooses an approach, trains and tunes candidate models, validates them honestly on a locked test set, and hands back the best validated model it finds, with a report.

In development Tabular classification & regression Windows Local-first
Download What is built today

Epoch does not promise the best possible model for every dataset. Some data is too small, mislabelled, or needs domain knowledge, and Epoch is designed to say so instead of manufacturing confidence. Parts of this page describe features still being built; each one is labelled.

Let Epoch decide In progress

Most people with a spreadsheet are not machine-learning specialists. Describe your data in plain words, or just say you do not know, and Epoch chooses the setup for you and explains each choice.

Example (illustrative)
“Customer records. I want to know who will leave.”
Epoch would decide and explain
  • the task (classification or regression) and the target column
  • the metric to optimise, and why it suits your data
  • the split strategy: stratified, random, grouped or time-ordered
  • the training budget and what to favour: accuracy, speed or simplicity
  • which columns to exclude, such as IDs or columns that leak the answer

It asks a question only when it is unsure, and flags low confidence rather than hiding it.

Status: the Advisor is being built now and is not in the current development build. In that build you choose the target and settings yourself; Epoch suggests a target and warns about problems. It is designed to work offline.

How it works

The workflow Epoch is built around. Each step shows whether it exists in the current development build.

  1. Import Implemented

    Bring in a CSV. Excel and Parquet are planned.

  2. Understand Implemented

    Profiles every column, finds missing values and duplicates, suggests a target, and warns about likely leakage and class imbalance.

  3. Plan In progress

    Today you pick the task and settings. The Advisor and an automatic planner that works within your time budget are being built.

  4. Train and tune In progress

    Several models train and are compared against a baseline, and you can cancel at any time. Automatic tuning and more model types are being built.

  5. Validate Implemented

    Models are selected on a validation set. The test set stays locked and is scored once for the final candidate; any repeat use must be acknowledged and is logged.

  6. Report Planned

    The current build shows metrics, a comparison against a baseline and a confusion matrix in the app. A full HTML and JSON report is planned.

  7. Try Planned

    A panel to load a CSV or fill in a single row and see predictions. Today you can export a bundle with an inference helper.

  8. Improve with more data Planned

    Add new data to an existing model, check it matches the old schema and has not drifted, refit, and compare old against new on the same locked test.

  9. Recommendations Planned

    Diagnose over-fitting, imbalance, small data or suspected label noise, and suggest what to change or which kind of data to add.

Trust principles

No leakage

Preprocessing is fitted inside the training data only. Epoch checks for columns that give away the answer and excludes ID-like columns. The check is a heuristic, so it warns rather than promises.

Locked test set

Validation chooses the model; the test set is for one honest final score. Using it again requires an explicit acknowledgement and is recorded.

Reproducible

Splits are seeded and each experiment keeps its settings and a fingerprint of the data it used. A fuller reproducibility record in the report is planned.

Local-first and private

Epoch is designed to run on your machine, with no required cloud account and no telemetry. This describes the app; this website itself uses Google Analytics like the rest of the site.

Epoch never reports a metric it did not compute, and does not show training scores as the headline.

FAQ

Will Epoch always find the best model?
No. It searches within a budget you set and reports the best validated model it found. If the data is too small, mislabelled or needs domain knowledge, Epoch is meant to tell you so.
What kinds of data does it support?
Today: tabular data from CSV files, for classification and regression. Time series, audio, images and text are planned, and a supported file format does not by itself mean a supported task.
Does it need the internet or an account?
It is designed to run locally with no account and no telemetry. Your dataset is meant to stay on your machine.
Does “Let Epoch decide” use a cloud AI?
No. It is designed to work offline, with no cloud AI required.
Is the development build safe to run?
Early builds are unsigned and were tested on one machine, so treat them as a preview. Only load exported models you created or trust.
Is Epoch open source? Is there a price?
No public source repository or support channel exists yet, and no pricing has been announced. Contact me below if you want to talk about it.
Where do I get older versions?
On the releases page, which lists every version with its notes.

Roadmap

In order of intent, not with dates.

  1. Tabular v0.1 Implemented

    CSV classification and regression, locked test set, export, desktop app.

  2. AutoML engine and Advisor In progress

    “Let Epoch decide”, automatic tuning, more models, budgets, smarter splits, combining models.

  3. Improve, recommend, report Planned

    Improve with more data, recommendations, HTML report, try-your-model, Excel and Parquet, safer export.

  4. Packaging and release Planned

    Clean-machine testing, code signing, installer, and a measured benchmark against other tools under equal budgets.

  5. Beyond tabular Planned

    Time series and signals, audio, then images and text; later multimodal, monitoring and remote workers.
