EPOCH

Give it a dataset. Epoch picks the method.

Epoch is a local-first AutoML workbench for tabular data. It analyses your dataset, chooses an approach, trains and tunes candidate models, validates them honestly on a locked test set, and hands back the best validated model it finds, with a report.

Beta Tabular classification & regression Windows Local-first
Download What is built today

Epoch does not promise the best possible model for every dataset. Some data is too small, mislabelled, or needs domain knowledge, and Epoch is designed to say so instead of manufacturing confidence. Anything not built yet is labelled Planned.

Let Epoch decide In the 0.2 beta

Describe your data in plain words, or just say you do not know, and Epoch chooses the setup and explains each choice. It works offline and asks a question only when it is unsure.

Example (illustrative)
“Customer records. I want to know who is likely to leave.”
Epoch decides and explains
  • what to predict and whether it is classification or regression
  • how to score models, and how to split the data (including same-person or time-ordered data)
  • how much effort to spend: Express, Balanced or Deep
  • which columns to leave out, such as IDs

You can change anything Epoch fills in. The advice is a starting point, and it flags low confidence instead of hiding it.

How it works

  1. Import

    Bring in a CSV. Epoch checks it and keeps your original untouched.

  2. Understand

    Profiles every column and warns about missing values, duplicates, imbalance and likely leakage.

  3. Plan

    Let Epoch decide, or choose yourself: target, score, split and effort.

  4. Train and tune

    Many model types are screened, the promising ones are tuned and cross-validated within a time budget, and an ensemble is kept only when the gain is meaningful.

  5. Validate

    The test set stays locked. It is scored once for the final model, and any repeat use is logged.

  6. Report

    An HTML report with the results, the limits and what to try next.

  7. Try

    Load a CSV or enter one example and see the predictions.

  8. Improve with more data

    Add a new dataset. Epoch checks it fits and has not drifted, retrains on old and new, and compares both models on the same locked test rows plus a held-out slice of the new data.

  9. Recommendations

    Suggests what to change: more rows or more columns, weak classes, instability, leakage.

Trust principles

No leakage

Preprocessing is fitted inside the training data only. Epoch checks for columns that give away the answer and excludes ID-like columns. The check is a heuristic, so it warns rather than promises.

Locked test set

Validation chooses the model; the test set is for one honest final score. Using it again requires an explicit acknowledgement and is recorded.

Reproducible

Splits are seeded and each experiment keeps its settings and a fingerprint of the data it used. A fuller reproducibility record in the report is planned.

Local-first and private

Epoch is designed to run on your machine, with no required cloud account and no telemetry. This describes the app; this website itself uses Google Analytics like the rest of the site.

Epoch never reports a metric it did not compute, and does not show training scores as the headline.

FAQ

Will Epoch always find the best model?
No. It searches within a budget you set and reports the best validated model it found. If the data is too small, mislabelled or needs domain knowledge, Epoch is meant to tell you so.
What kinds of data does it support?
Today: tabular data from CSV files, for classification and regression. Excel and Parquet, time series, audio, images and text are planned.
Does it need the internet or an account?
It is designed to run locally with no account and no telemetry. Your dataset is meant to stay on your machine.
Does “Let Epoch decide” use a cloud AI?
No. The Advisor runs offline on your machine.
Is the beta safe to run?
Early builds are unsigned and were tested on one machine, so treat them as a preview. Only load exported models you created or trust.
Is Epoch open source?
The source code is public at github.com/kailu687/epoch. No pricing has been announced. Contact me below with questions.
Where do I get older versions?
On the releases page, which lists every version with its notes.
